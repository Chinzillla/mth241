How to choose a method

Start with one outcome. Are you counting a committee, an ordered list, a flavor-count vector, a card hand, or a stopped sequence? State what would make two outcomes different.

  1. Are there labeled positions or roles? Would swapping two selected objects change the result?
  2. Can an object or category repeat? Distinguish repeated types from repeated physical objects.
  3. Are objects distinct? Are boxes, groups, or positions labeled?
  4. Do restrictions suggest blocks, gaps, a lower-bound shift, symmetry, a complement, or disjoint cases?

The table gives basic models, not a substitute for checking restrictions. An increasing sequence has a unique order once its members are chosen. Stars and bars keeps the categories labeled: exchanging the x and y counts generally changes the solution.

Add, multiply, divide, or subtract?

Multiply successive choices when each count is valid given earlier choices. Add disjoint, exhaustive cases. Subtract a complement when the forbidden case is simpler. Divide only after identifying a constant number of descriptions for every final object.

The counting multiplication principle does not require probabilistic independence. Multiplying unconditional probabilities generally does.

For probability questions

Check whether elementary outcomes are equally likely. If information is given, condition on it. If there are several sources, average over a source partition. If an observed result is used to infer its source, use Bayes. Check independence before replacing conditional probabilities with unconditional factors.

Explain the setup

Counting

Define the object. For each stage, say whether order matters and repetition is allowed. Explain every factor or case. State why every valid outcome is counted exactly once.

Probability

Define the sample space and event. Explain equal likelihood or assign weights. Use a consistent ratio, conditional expression, or sum of disjoint events.

Proofs

For counting identities, describe the same collection on both sides. For probability identities, write a set decomposition, show the pieces are disjoint, and name the axiom that justifies the next step.

For example, drawing 2 black and 1 white ball uniformly without replacement from 5 black and 6 white distinct balls gives (52)(61)/(113). The numerator selects the required colors; the denominator counts any three-ball subset. Every such subset is equally likely. Numerical evaluation is unnecessary.

Avoid keyword-only decisions. “Choose” can describe assigning distinct offices. “And” does not alone justify multiplying probabilities. Identify the mathematical structure.
