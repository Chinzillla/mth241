## Important Words
- Order
- Repetition

Division - When there are duplicates that affect the outcome

Everytime you are given a multi-tiered counting question, break each task into non-overlapping(discrete) parts:
- multiplicative (*) or additive (+)
- order matters
- repetition allowed

Each Task answer the following questions:

## Theorem
The number of ways to order r objects from a set of objects if repetition is allowed is n^r

example:

6 letters in alphabet, how many 4 digit passwords if 
- (a) No digit is repeated?
ans = 6 * 5 * 4 * 3

- (b) No digit occurs consecutively
ans = 6 * 5 * 5 * 5
