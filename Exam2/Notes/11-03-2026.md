Formula of Variance
```
Var(X) = E((x - mean)^2)
mean = E(X)
= E((x - E(x))^2)
= E(x^2) - E(2xmean) + E(mean^2)
= E(x^2) - 2mean * E(x) + mean^2

if mean = E(x)

= E(x^2) - 2 E(x) * E(x) + E(x)^2
= E(x^2) - 2 E(x)^2 + E(x)^2
= E(x^2) - E(x)^2
 
E(aX +b) = aE(x) + b
```

Q. Var(aX + b) = a^2 Var(X)
```
Var = E[(aX+b)^2] - [E(aX + b)]^2
= E[a^2x^2+2abx+b^2] - (aE(x) + b)^2
= a^2E(x^2) + 2abE(x) + E(b^2) - a^2E(x)^2 + 2abE(x) + b^2
- E(b^2) is same as b^2 so cancel out
- 2abE(x) cancel out
= a^2E(X^2) - a^2E(X)^2
= a^2[E(x^2) - [E(x)]^2]
= a^2 Var(x)
```
