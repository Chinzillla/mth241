```

    0 if x < 1

    2/4 if x = 2
    1/8 if x = 3
    1/8 if x = 4 
    0 if x > 4
}

F(X = i) = {
    0, if x < 1
    1/4, if 1 <= x < 2
    3/4, if 2 <= x < 3
    7/8, if 3 <= x < 4 
    1, if x <= 4
    1, if x > 4
}

P(2) = 2/4
P(3) = 1/8
P(4) = 1/8
```
